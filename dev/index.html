Library Bookmarklets — Dev Harness

These bookmarklets normally run as javascript: links against live library web apps. This local harness mocks the relevant pages so each script can be exercised in a browser during development. Use the blue toolbar at the top to run a bookmarklet against the current page.

Calculator

A floating calculator overlay that works on any page. Click Calculator in the toolbar above to launch it here, then type a calculation.

Source: calculator.js

SILO ILL helpers

ILLCart.js and ILLSearch.js target the live SILO ILL and Booksys/Atriuum web apps (they read borrower/lender transaction markup and drive a Select2 widget). They require those external sites and are not exercised by this local harness.
